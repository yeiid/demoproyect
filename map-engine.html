Capacidades
del motor

🗺️ Vector Tiles MVT

Martin renderiza tiles directamente desde PostGIS. Rendimiento optimizado con cache de 7 dias y gzip en protobuf.

📥 Ingesta Masiva

Importacion con ogr2ogr + PG_USE_COPY. GPKG de 3GB en 8-15 min. Importacion incremental con hash MD5 por capa.

🎨 Estilos Dinamicos

Style.json generado automaticamente desde las capas en PostGIS. Colores unicos por capa, 3D extrusiones desde zoom 13+.

🔐 Auth JWT

Autenticacion completa. Panel admin con estadisticas, jobs de importacion y gestion de usuarios.

⚡ Optimizado

Pool de conexiones SQLAlchemy, cache de style.json con TTL, COUNT por pg_stat, track_usage en memoria.

🌐 API REST

Endpoints para config, layers, auth, admin. Vista publica sin autenticacion para compartir mapas.

// arquitectura

Stack
tecnico

🗄️ PostgreSQL + PostGIS

Base de datos espacial con indices GIST. Optimizada para tiles protobuf y consultas geoespaciales.

🗺️ Martin Tile Server

Servidor de Vector Tiles MVT que lee directo de PostGIS. Sin cache intermedio, datos siempre frescos.

⚡ FastAPI Manager

API para estilos dinamicos, auth, ingesta de datos y jobs asincronos. Python 3.11 + SQLAlchemy.

🔀 Nginx Gateway

Reverse proxy con gzip para tiles protobuf, CORS, cache de tiles 7 dias y compresion.
